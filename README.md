# Digital System Laboratory

此專案為國立中山大學 (NSYSU) 資訊工程學系「數位系統實驗」課程的作業與實驗報告存放區。

每個資料夾皆以日期命名，對應於當週的實驗內容。

## Assignments Overview

以下是此專案中各個資料夾所涵蓋的實驗單元簡介：

| 日期 | 實驗編號 | 實驗主題 |
| :--- | :--- | :--- |
| `0918` | Lab 03 | **Boolean Algebra 1** ( 布林代數一 ) |
| `0923` | Lab 04 | **Boolean Algebra 2** ( 布林代數二 ) |
| `0925` | Lab 05 | **Canonical and Standard Forms** ( 標準式與典型式 ) |
| `1002` | Lab 06 | **Digital Logic Gates** ( 數位邏輯閘 ) |
| `1016` | Lab 07 | **Karnaugh Map** ( 卡諾圖 ) |
| `1023` | Lab 08 | **Karnaugh Map (2)** ( 卡諾圖二 ) |
| `1030` | Lab 09 | **Adders** ( 加法器 ) |
| `1106` | Lab 10 | **Magnitude Comparator, Decoder and Multiplexer** ( 數值比較器、解碼器與多工器 ) |
| `1113` | Lab 11 | **7-bit Hamming Code** ( 7位元漢明碼 ) |
| `1120` | Lab 12 | **Analysis of Synchronous Sequential Logic** ( 同步序向邏輯分析 ) |
| `1127` | Lab 13 | **Design of Synchronous Sequential Logic** ( 同步序向邏輯設計 ) |
| `1204` | Lab 14 | **Registers & Counters** ( 暫存器與計數器 ) |
| `1211` | Lab 15 | **Memory** ( 記憶體 ) |
